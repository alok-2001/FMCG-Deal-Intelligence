# FMCG Deal Intelligence

A Python-based pipeline that collects FMCG deal-related news, removes duplicate articles, evaluates relevance and source credibility, and creates a structured newsletter.

---

## Key Features

- 📰 **News Collection**  
  Collects FMCG deal-related news from configured sources.

- 🔄 **Duplicate Detection**  
  Identifies and merges similar news articles to avoid repeated deals.

- 🎯 **Relevance Scoring**  
  Scores articles based on their relevance to FMCG transactions.

- 🛡️ **Credibility Evaluation**  
  Provides a credibility score and tier for each source.

- 🌍 **Category and Region Filters**  
  Supports FMCG category selection and region-based filtering for live searches.

- 🔍 **Transparent Scoring Trail**  
  Shows why an article was included, excluded, or merged as a duplicate.

- 📬 **Newsletter Generation**  
  Generates a structured FMCG deal newsletter from the selected articles.

- 📊 **Multiple Downloads**  
  Download results as:
  - Excel newsletter
  - Markdown newsletter
  - Raw CSV data

- ⚡ **Demo and Live Modes**  
  Use cached demo data for quick testing or run a live news search.
